# 🏛️ مكتب الهيبه للمحاسبة والأعمال الهندسية
### المنظومة الرقمية المتكاملة لإدارة المعاملات الهندسية، التصالحات، والتراخيص
**تحت إدارة: المحاسب / منصور هيبه — الإسكندرية (مدينة العامرية)**

---

## 🌟 نظرة عامة على المشروع

منظومة ويب متطورة مصممة خصيصاً لمكتب الهيبه للمحاسبة والأعمال الهندسية. توفر المنظومة تجربة متكاملة تبدأ من البوابة العامة للمواطنين، ونظام تقديم الطلبات التفاعلي وتتبع المعاملات بالرقم، وحتى لوحة الإدارة المتطورة للمكتب التي تدعم وضع عدم الاتصال (Offline-First)، والتحليلات المالية اللحظية، والأرشفة السحابية على **Cloudflare R2**.

---

## ✨ المميزات الرئيسية

### 1. بوابة المواطنين العامة (Public Portal)
- **واجهة عصرية بهوية مصرية رصينة:** مصممة بألوان متوازنة ومريحة للعين تعكس الوقار والمصداقية.
- **خدمات المكتب الهندسية والمحاسبية:** استعراض تفصيلي لخدمات (التصالح في مخالفات البناء، تراخيص البناء والهدم، رخص المحلات العامة، تقنين أراضي الدولة، والرفع المساحي).
- **دليل المستندات التفاعلي (Interactive Checklist):** أداة تتيح للعميل اختيار المعاملة والتعليم على الأوراق المجهزة وحساب نسبة اكتمال ملفه مع خيار طباعة الكشف أو إرساله للواتساب.
- **قسم الأسئلة الشائعة (FAQ Accordion):** دليل شامل وإجابات قانونية وفنية حول قانون التصالح 2024 ونموذج 8 وإجراءات الحي مع شريط بحث فوري.
- **شاشة حجز سريعة على 3 خطوات:** توليد كود حجز فوري مثل `HB-2026-XXX` مع زر نسخ الكود ومشاركته مباشرة على الواتساب.
- **نظام التتبع الحي (Live Tracking):** استعلام بالرقم أو الهاتف لمشاهدة المراحل الإجرائية الخمس والموقف المالي وأزرار التواصل المباشر.

### 2. لوحة الإدارة والتحكم (Admin Dashboard)
- **مسار مخصص ومحمي:** دخول آمن ومنفصل تماماً عبر الرابط `/admin` مع حفظ جلسة الدخول.
- **بنية أوفلاين فيرست (Offline-First):** تخزين محلي Persistent IndexedDB مع Firebase Firestore يعمل بكفاءة 0ms حتى في حالة انقطاع الإنترنت.
- **فصل طلبات الموقع عن معاملات المكتب:** فلاتر ذكية تميز بين `🌐 طلب أونلاين` (أتعاب غير محددة) و `🏛️ يدوي مكتب`.
- **نظام المدفوعات والتفقيط التلقائي:**
  - زر سداد دفعة مرتبط مباشرة بملف العميل وحساب الرصيد المتبقي دون كتابة بيانات يدوية.
  - محرك تفقيط عربي للجنيه المصري (مثال: `5000` -> `خمسة آلاف جنيه مصري فقط لا غير`).
  - طباعة سند قبض رسمي معتمد A4 بهوية المكتب وبيانات المدير.
- **لوحة التحليلات المالية (Financial Analytics):**
  - رسم بياني شهري تفاعلي حقيقي 100% محسوب من واقع سندات القبض.
  - مؤشرات أداء KPI مالية، وتوزيع طرق الدفع (كاش، إنستاباي، بنكي)، ونسب استيفاء الدفعات.
- **الأرشفة السحابية (Cloudflare R2):**
  - رفع وإدارة المستندات الهندسية ورخص المباني مباشرة على سحابة Cloudflare R2 السريعة والمحمية مع تاريخ الرفع وحجم الملف والملاحظات.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 18, TypeScript, Vite
- **Styling & UI:** Tailwind CSS, Lucide React Icons
- **Database & Offline Cache:** Google Firebase Firestore, Persistent Local Cache
- **Cloud Storage:** Cloudflare R2 (S3-Compatible API عبر `@aws-sdk/client-s3`)
- **Deployment:** Vercel / Cloudflare Pages Ready
